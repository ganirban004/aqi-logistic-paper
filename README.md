# Modeling Seasonality of Categorical Time Series Using Fourier Series with Application to AQI Data of Kolkata

Although Markov models such as MTD, PAR, DARMA, and regime-switching DARMA are widely used for modeling categorical time series like daily AQI categories, they offer limited flexibility in incorporating exogenous variables such as seasonal effects. On the other hand, the machine learning and deep learning models include exogenous variables, but they lacks interpretability. This study aims to develop an ordinal logistic regression model to predict daily AQI categories for Kolkata, using various seasonal components as inputs. Given that AQI is reported in ordered categories, this approach offers interpretable and policy-relevant insights. We compare its performance with discrete-time Markov chain models and machine learning and deep learning classifiers. While various machine learning and deep learning models are considered, the Fourier series based ordinal logistic regression achieves the highest forecasting accuracy, demonstrating that this interpretable framework offers both effectiveness and transparency in AQI prediction. The model is suitable for long-term AQI monitoring and supports informed environmental decision-making in urban settings.
